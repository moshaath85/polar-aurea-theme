# Changelog

All notable changes to the **Aurea** theme are documented here.

## [1.0.0] — 2026-09-17

### Added
- Cinematic hero component with crossfade, Ken Burns motion, progress bars, swipe and per-slide content.
- Outline ticker (marquee) component.
- Category tiles component.
- Featured products component (uses Salla's native products slider).
- Lookbook horizontal drag/scroll component.
- Editorial split component with stats.
- Brand story component.
- Service highlights component.
- Testimonials component.
- Newsletter component.
- Premium header (sticky, announcement marquee) and footer built on Salla web components.
- Product page with gallery, options, quantity, add-to-cart, shipping notes, accordion description and related products.
- Category/listing page with filters and sorting.
- Cart, informative page, thank-you, blog index/single and brands index templates.
- Full RTL/LTR support, Arabic/English strings, reduced-motion support.
- Progressive enhancement: the theme renders correctly with JavaScript disabled.

### Notes
- Default content ships with the theme so the store looks complete right after installation.
- Images are WebP and optimized; the built theme stays well under the 1MB public-size limit.
